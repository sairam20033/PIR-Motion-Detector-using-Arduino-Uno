# PIR-Motion-Detector-using-Arduino-Uno
Developed a motion detection system using a PIR (Passive Infrared) sensor and Arduino Uno to detect human movement in real time. The system continuously monitors motion activity and triggers an output response whenever movement is detected within the sensor's range.

A simple embedded system project that detects human motion using a PIR (Passive Infrared) sensor and Arduino Uno. When motion is detected, the system triggers an output response, making it suitable for basic security and automation applications.

## Features

- Real-time motion detection
- Arduino Uno and PIR sensor interfacing
- Simple and cost-effective implementation
- Easy to expand for IoT and automation projects

## Components Used

- Arduino Uno
- PIR Motion Sensor
- Breadboard
- Jumper Wires
- LED/Buzzer (Optional)

## Technologies

- Arduino IDE
- Embedded Systems
- Sensor Interfacing
- C/C++ (Arduino Programming)

## Working

The PIR sensor continuously monitors infrared radiation in its surroundings. When a moving object, such as a person, enters the detection area, the sensor sends a signal to the Arduino Uno. The Arduino processes this signal and activates the connected output device.
